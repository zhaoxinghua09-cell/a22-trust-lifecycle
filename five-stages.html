A.2.2 · 信任生命周期的五个阶段

阶段边界画在所需证据发生变化的地方，不画在组织责任变化的地方。每个阶段有 entry / exit 条件，以及该阶段最容易静默失败的方式。

五阶段

L1
登记Registration
进入条件
operator asserts the agent exists
退出条件
resolvable record + named governance owner
静默失败
registered for inventory, reported as governed
L2
授权Authorisation
进入条件
agent is registered
退出条件
scope of authority declared and bounded, traceable to a conferral
静默失败
authority asserted, not traceable
L3
运行Operation
进入条件
agent acts
退出条件
per-act evidence: what was done, on what inputs, on what basis
静默失败
acts executed, evidence produced after the fact
L4
重评Re-evaluation
进入条件
new evidence, or a change to the reference
退出条件
state re-derived; previous state superseded explicitly
静默失败
previous state persists, nobody re-derived
L5
退休Retirement
进入条件
agent stops acting
退出条件
record closed; standing terminally withdrawn
静默失败
decommissioned in practice, still active on record

四个可跑案例（lifecycle_demo.py）

#案例检出为什么这个案例存在
1合规走完五阶段无检出每阶段 evidence=verified / authority=in-force
2证据缺失但授权在效允许但无据L3 无逐动作证据，授权仍 in-force —— 合法态，单值表示会误报
3证据好但授权已撤销危险方向L3 evidence=verified 但 authority=revoked —— 好证据推不出有权
4记录取不到无判定不可达时必须报 determination unavailable，不得默认放行或拒绝
