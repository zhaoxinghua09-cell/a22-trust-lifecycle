# A.2.2 — Trust lifecycle framework, with a runnable demo

Input document for ITU-T FG-TIDA work item **A.2.2** (a trust lifecycle framework for
agentic AI), with an executable demonstration of its evidence criteria.

**Status:** submitted to the FG-TIDA secretariat on 28 November 2026 as an input
document for the 1st in-person meeting (Paris, 30 November – 1 December 2026), in Word
form. Offered for discussion; not adopted, not a settled position, and not an ITU-T
Recommendation.

## Contents

| File | What it is |
|---|---|
| `A22.md` | the input document: five lifecycle stages, two axes, per-stage evidence criteria |
| `contribution/src/doc/index.rst` | the same document as a reStructuredText package in the FG-TIDA template layout (entry document; chapters under `chapters/`) |
| `lifecycle_demo.py` | a worked implementation of the five stages with four cases |
| `five-stages.html` | the two-axis state space, self-contained, opens offline |

## Run the demo

No dependencies, Python 3.8+, offline.

```bash
python lifecycle_demo.py
```
